نصب گامبهگام سامانهٔ بابل طیور

از دانلود تا اولین ورود — فقط با چند کلیک. نیازی به نصب SQLite، SQL Server یا هیچ درایوری نیست.

نسخهٔ راهنما: فاز ۳ — ۲۸ اکتبر ۲۰۲۶

❓ آیا باید SQLite نصب کنم؟ — خیر، اصلاً.

SQLite یک نرمافزار سرور نیست که نصب شود؛ یک کتابخانه است که داخل خود Node.js نسخهٔ ۲۲٫۵ به بعد کامپایل شده است. نصبکننده Node.js را خودکار نصب میکند، پس SQLite هم همراهش میآید. دیتابیس فقط یک فایل است:

C:\BabolToyor\data\baboltoyoor.db

نه سرویس SQL، نه sqlite3.exe، نه ODBC، نه نام کاربری/رمز جداگانه. هیچ چیزی از sqlite.org دانلود نکنید مگر اینکه خودتان خواسته باشید دیتابیس را با ابزار گرافیکی نگاه کنید (کاملاً اختیاری — بخش پرسشهای متداول).

گام ۱ — دانلود فایلها

حالت الف: سرور به اینترنت وصل است (پیشنهادی)

همین یک فایل کافی است:

⬇️ دانلود BabolToyor-Windows-Setup-1.1.15.zip
حدود ۴٫۲ مگابایت • پوشهٔ انتشار Google Drive

نصبکننده خودش Node.js را از winget یا سایت رسمی nodejs.org میگیرد و چکسام SHA-256اش را چک میکند.

حالت ب: سرور هیچ اینترنتی ندارد

علاوه بر ZIP بالا، یک فایل دیگر هم لازم است: نسخهٔ پورتابل Node.js 22 LTS (64-bit).

  • بروید به nodejs.org/en/download → بخش Standalone Binary / Windows x64 (.zip)، یا nodejs.org/dist → پوشهٔ v22.x.x/.
  • فایلی شبیه node-v22.22.3-win-x64.zip بگیرید (حتماً x64، حتماً zip).
  • آن را همانطور ZIPشده (بدون استخراج) کنار BabolToyor-Setup.cmd بگذارید.

در حالت آفلاین، نصبکننده هیچ چیزی روی ویندوز نصب نمیکند و هیچ اینترنتی لازم نیست. فایل MSI یا نسخهٔ ۳۲بیتی (x86) برای این حالت مناسب نیست.

گام ۲ — انتقال و استخراج

۱

یک پوشهٔ ساده بسازید

مثلاً C:\BabolToyor-Install و فایلهای دانلودشده را با فلش، شبکه یا RDP به آن کپی کنید.

اگر ویندوز گفت فایل بلاک شده: راستکلیک → Properties → تیک Unblock → OK.

۲

ZIP را استخراج کنید

راستکلیک روی BabolToyor-Windows-Setup-1.1.15.zip → Extract All... → Extract.

حالا باید این سه فایل کنار هم باشند:

C:\BabolToyor-Install\
  ├── BabolToyor-Setup.cmd      ← نصبکننده
  ├── app.zip                   ← فایلهای سامانه
  └── README-INSTALL-fa.txt     ← راهنمای داخل بسته

در حالت آفلاین، node-v22.x.x-win-x64.zip هم همانجا باشد. app.zip را جدا نکنید و جابهجا نکنید.

گام ۳ — اجرای نصبکننده

۱

راستکلیک → Run as administrator

روی BabolToyor-Setup.cmd راستکلیک کنید و Run as administrator را بزنید. (دابلکلیک هم خودش UAC میدهد.)

۲

پنجرهٔ UAC → Yes

پیام «Do you want to allow this app to make changes?» → Yes. پنجرهٔ مشکی Command Prompt باز میشود؛ آن را نبندید.

اگر پیام Execution Policy یا SmartScreen آمد، نگران نباشید؛ فایل .cmd با Bypass اجرا میشود. فقط Unblock گام ۲ را انجام دهید.

۳

منتظر بمانید — ۲ تا ۱۰ دقیقه

نصبکننده بهترتیب: Node.js 22.5+ (و همراهش SQLite)، آزادسازی پورت ۸۰ از IIS، کپی برنامه به C:\BabolToyor، ساخت دیتابیس، باز کردن فایروال TCP 80، ساخت تسک اجرای خودکار با ریاستارت در خطا، ساخت رمز تصادفی مدیر، تست سلامت و میانبر دسکتاپ.

۴

گام ۴ — اولین ورود

۱

باز کردن سامانه

روی خود سرور: http://localhost — از کامپیوتر دیگر: http://IP-سرور (مثلاً http://192.168.1.50). بدون نوشتن پورت.

۲

رمز اولیه

فایل C:\BabolToyor\INSTALL-INFO.txt را با Notepad باز کنید؛ نام کاربری admin و رمز تصادفی داخلش است.

۳

تعویض اجباری رمز

سامانه در اولین ورود رمز جدید میخواهد. رمزی قوی (حداقل ۸ کاراکتر، حروف بزرگ و کوچک + عدد + نماد) انتخاب و در جای امنی یادداشت کنید.

🔒 بعد از تعویض رمز، فایل INSTALL-INFO.txt را پاک کنید چون رمز اولیه داخلش است.

۴

بررسی سلامت (اختیاری)

در Command Prompt داخل همان پوشه:

cd /d C:\BabolToyor-Install
BabolToyor-Setup.cmd status

باید Port 80 : LISTENING و Health : HTTP 200 OK ببینید. ✅

پرسشهای متداول

۱) SQLite — کدام نسخه و از کجا؟

هیچکدام و از هیچ جا. ماژول node:sqlite از Node.js 22.5.0 به بعد جزو خود Node است. نصبکننده خودش دیتابیس را میسازد. مستندات رسمی Node.js.

۲) پس دقیقاً چه نرمافزاری نصب میشود؟

فقط Node.js 22.5+ (ترجیحاً LTS) — و آن را هم نصبکننده انجام میدهد. اگر خواستید دستی بدهید: nodejs.org/en/download → LTS → Windows Installer (.msi) x64. نسخههای ۲۰ و قدیمیتر کار نمیکنند.

۳) دلم میخواهد خود دیتابیس را ببینم (کاملاً اختیاری)

بدون نصب چیز اضافی، از ابزار داخلی سامانه:

cd /d C:\BabolToyor
node scripts\sql-query.js --stats
node scripts\sql-query.js "SELECT order_no, status FROM orders"

یا ابزار گرافیکی اختیاری: صفحهٔ دانلود SQLite → Precompiled Binaries for Windows → sqlite-tools-win-x64-3540100.zip (SQLite 3.54.1) را در C:\sqlite استخراج کنید؛ یا DB Browser for SQLite. عدد انتهای نام فایل نسخه است (3540100 = ۳٫۵۴٫۱)؛ همیشه آخرین نسخهٔ همان صفحه را بگیرید. برای نصب سامانه لازم نیست.

۴) اطلاعات قبلی (db.json) چه میشود؟

اولین اجرا خودکار به جداول SQL منتقل میکند و فایل قدیمی را به db.json.migrated-<تاریخ> تغییر نام میدهد — چیزی از بین نمیرود.

۵) امنیت

پیشفرض HTTP روی پورت ۸۰ است (چون پورت نوشته نشود). رمزها هش میشوند، نشست و Audit لاگ دارند. اگر بعدها HTTPS/reverse proxy اضافه کردید، در .env مقادیر COOKIE_SECURE=true و TRUST_PROXY=true را بگذارید.
