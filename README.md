# سامانهٔ هوشمند بابل طیور — نسخهٔ انتشار ۱٫۱٫۱۲

سامانهٔ عملیات بابل طیور: نگهبانی (ثبت ورود/کنترل خروج)، فروش (سفارش عادی و فروشگاهی، تسویه)، فروشگاه (ثبت سفارش و پیگیری)، انبار (ورودی، آماده‌سازی و سرویس‌های ارسال، سوابق و گزارشات) و رانندگان/پیک‌ها.

شمارهٔ انتشار عمومی در `RELEASE_VERSION.txt` است. شمارهٔ داخلی سازگاری `37.6.0` و پین‌های فایل‌های ظاهری مستقل از شمارهٔ انتشار عمومی هستند. [دریافت نسخهٔ 1.1.13 از پوشهٔ Google Drive](https://drive.google.com/drive/folders/1TwKiI2xuxpY019LyukT1cXL1MT2jGjg9).

## اجرا
- نیازمندی: ‎Node.js 22.13+‎ — بدون نصب وابستگی در سرور (‏`npm install`‏ لازم نیست؛ SQLite داخلی Node و کلاینت ACME همراه بسته است).
- شروع: ‏`node server.js`‏
- پایگاهداده: **SQLite (SQL واقعی)** در `DATA_DIR/baboltoyoor.db` — جداول و ستونهای ایندکسهشده؛ راهنما: `docs/sqlite-database-fa.md`.
- متغیرهای محیطی: ‏`PORT`‏ (پیش‌فرض ۳۰۸۰)، ‏`HOST`‏، ‏`DATA_DIR`‏ (پوشهٔ دیتابیس؛ پیش‌فرض ‎`data/`‎ کنار پروژه)، ‏`SQLITE_FILE` (مسیر دلخواه فایل SQLite)، `ADMIN_INITIAL_PASSWORD`‏ (رمز اولیهٔ مدیر در اولین ساخت دیتابیس؛ مدیر در اولین ورود باید رمزش را عوض کند).
- **نصب یککلیک روی ویندوز سرور ۲۰۲۵:** ‏`windows-installer/BabolToyor-Setup.cmd`‏ — بدون کدنویسی، همهچیز خودکار و سامانه روی **پورت ۸۰** (`http://IP-سرور` بدون پورت). راهنما: ‏`windows-installer/INSTALL-STEPS-fa.md`‏ (**گامبهگام و قابلچاپ**)، ‏`windows-installer/README-fa.md`‏ و ‏`docs/deployment-windows-server-2025.md`‏. نصب SQLite جداگانه لازم نیست؛ همراه Node.js است.
- اجرای دستی روی ویندوز: ‏`scripts/start.ps1`‏ یا ‏`scripts/start-hidden.ps1`‏.
- ابزارهای SQL: `node scripts/sql-query.js "SELECT ..."` و پشتیبانگیری `node scripts/backup-db.js`.
- مسیرهای API از لایهٔ `lib/sql-repos.js` با prepared statement استفاده میکنند و دادهها در ابتدای هر درخواست از SQL تازه میشوند (فاز ۲). در **فاز ۳** نوشتها هم ردیفبهردیف شدند: هر تغییر همان لحظه `INSERT ... ON CONFLICT DO UPDATE` یا `DELETE` اجرا میکند و `store.save()` فقط همگامسازی افزایشی است (`docs/sqlite-database-fa.md` ← فاز ۳).
- پل باسکول (نمایشگر ‎PU 850‎): ‏`node scripts/weighbridge-bridge.js --port COM3 --baud 9600 --server http://127.0.0.1 --token <TOKEN>`‏ — مستند پروتکل: ‏`docs/weighbridge-pu850.md`‏.

## شروع از صفر (دیتای خام)
در اولین اجرا با یک ‏`DATA_DIR`‏ خالی، سامانه خودکار پایگاه‌داده را می‌سازد: تنها کاربر ‏`admin`‏ و کاتالوگ استاندارد ۹۰ محصول پیش‌فرض؛ بدون هیچ مشتری، کاربر یا سفارش دیگری.
رمز اولیهٔ مدیر را با ‏`ADMIN_INITIAL_PASSWORD`‏ بدهید؛ اگر تنظیم نشود، سامانه رمزی تصادفی می‌سازد و فقط یک‌بار در کنسول چاپ می‌کند. با کاربر ‏`admin`‏ وارد شوید؛ سامانه در اولین ورود تعویض رمز را اجباری می‌کند، سپس کاربران هر نقش را از پنل مدیریت بسازید.
> پوشهٔ ‏`fresh-data/`‏ که در تحویل‌های قبلی کنار بسته ارائه می‌شد، جزو این مخزن گیتهاب نیست؛ همان دیتای خام با اجرای اولیهٔ بالا به‌دست می‌آید.
> صحت فایلهای بسته: `sha256sum -c SHA256SUMS.txt` (بدون خود فایل مانیفست و `node_modules`).
> دیتابیس دیگر فایل JSON نیست؛ سرور در اولین اجرا `db.json` قدیمی را خودکار به جداول SQL منتقل و بایگانی میکند.
