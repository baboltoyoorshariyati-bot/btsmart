**دامنه:** فقط لایهٔ نمایش. هیچ خطی از منطق کاری، API، محاسبهٔ وزن/ناخالصی و گردش سفارش تغییر نکرد.

## ۱) چه چیزی اضافه شد

| فایل | نقش |
|---|---|
| `public/ui-compact-v2.css` | تمام تغییرات چیدمان، در **یک** فایل، آخرین stylesheet |
| `public/ui-compact-v2-loader.js` | بارگذار فایل بالا + کلید خاموش/روشن (`?ui=classic` / `?ui=new`) |
| `public/index.html` | فقط دو خط: یک `<script src>` پیش از `</head>` |

هیچ فایل CSS قبلی (styles، design، mobile، theme، form-layout، invoice-compact، warehouse-document، compatibility، transport-resources، responsive) **تغییر نکرده**؛ به همین دلیل بازگشت، حذف یک لایه است، نه بازسازی.

### فاز ۱
- هدر: از حالت ستونی و ۱۳۳px به **یک ردیف ۵۶px** (چسبان) در همهٔ عرض‌ها؛ عنوان با `ellipsis` کوتاه می‌شود.
- ردیف‌های کارتابل: از نوار `width:max-content` (۱۱۰۶ تا ۱۲۲۶px) به **کارت ۱۰۰٪** با سه ناحیه: نام + وضعیت / سه جفت داده / نوار عملیات.
- بریدگی و اسکرول افقی: قفل عرض‌ها و `nowrap` برداشته شد؛ نوارهای افقی فهرست‌ها غیرفعال شد.

### فاز ۲
- **نوار عملیات چسبان** روی برگهٔ وزن، فرم فروش و نگهبانی؛ در موبایل دکمهٔ اصلی تمام‌عرض و دو دکمهٔ فرعی کنار هم.
- پیام سیستم از مسیر دکمه‌ها کنار رفت (در موبایل بالای صفحه نمایش داده می‌شود).
- کف اندازه: هیچ متن ریزتر از ۱۱px، هیچ دکمهٔ زیر ۳۶px (لمسی ۴۴px).
- راهنماهای بلند دو خط شدند؛ ورودی‌ها در موبایل ۱۶px (بدون زوم ناخواسته).
- محتوای مودال سند در صفحه‌های کوچک تمام‌عرض و بدون قفل عرض.

## ۴) نقطهٔ بازگشت (سه راه، از سریع‌ترین به کامل‌ترین)

### راه ۱ — خاموش‌کردن فوری، بدون انتشار نسخهٔ جدید
در مرورگر همان کاربر، آدرس سامانه را با پارامتر زیر باز کنید:

```
http://<آدرس-سرور>/?ui=classic
```

لایهٔ جدید بارگذاری نمی‌شود و ظاهر قبلی برمی‌گردد. انتخاب در همان مرورگر ذخیره می‌شود (تا وقتی خودتان برنگردانید). برای برگشت به ظاهر جدید:

```
http://<آدرس-سرور>/?ui=new
```

> برای همهٔ کاربران به‌صورت همیشگی: در `public/index.html` خط `<script src="/ui-compact-v2-loader.js?v=37.6.0"></script>` را حذف کنید (یا کامنت کنید). همین یک خط کافی است؛ هیچ CSS دیگری دست‌کاری نشده.

### راه ۲ — بازگشت با گیت (کل تغییرات این مرحله)
تگ نقطهٔ بازگشت: **`ui-v2-rollback-point`** (کامیت `5fb07fb`، یعنی درست پیش از افزودن لایهٔ جدید).

```bash
git fetch --tags
git revert --no-edit <کامیت-فاز-۱و۲>      # بازگشت نرم با تاریخچه
# یا اگر می‌خواهید کل کار به حالت آن تگ برگردد:
git checkout ui-v2-rollback-point -- public/ui-compact-v2.css public/ui-compact-v2-loader.js public/index.html lib/http.js
```

### راه ۳ — حذف کامل فایل‌ها
```bash
rm public/ui-compact-v2.css public/ui-compact-v2-loader.js
```
و حذف دو خط `STATIC` از `lib/http.js` و یک خط `<script>` از `public/index.html`. تا وقتی آن خط در `index.html` هست، فایل نبودن CSS فقط هشدار کنسول می‌دهد و ظاهر قبلی سر جایش است.
